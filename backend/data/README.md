# Seed Dataset

`respiratory_seed_cases.csv` bu real klinik ma'lumot emas. U diplom loyihasining boshlang'ich ML pipeline qismini ishga tushirish uchun tuzilgan sintetik seed datasetdir.

Keyingi bosqichda:

1. Kaggle, UCI yoki CDC manbalaridan haqiqiy ochiq dataset topiladi.
2. Shu seed dataset o'rniga yoki yoniga real tozalangan dataset qo'yiladi.
3. `scripts/train_baseline_model.py` real dataset bilan qayta ishlatiladi.
